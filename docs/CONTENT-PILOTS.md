# 六个内容样板：真实任务与边界

`src/templates/pilots.js` 为六个优先知识点提供有界候选池。非样板点返回 `null` 交由基础引擎处理；样板点不支持的维度或等级返回空数组，不借用其他知识点补题。最终题序由版本化种子与组卷器决定。

## 任务设计

- **cnm_p020 · 9加几**：十框计算；凑十过程分为“补给9、剩余、得数”三个小问；给定总量反推加入量；补偿等式中的未知量；比较9加几与10加几的真假判断。加数2—9，不再把所有空都设计成9。起步可以数给定点阵，进阶撤去重复点阵，挑战减少支架。
- **cnm_p018 · 20以内不进位加法**：数位表；缺第二加数与缺第一加数；从结果逆推；数位分解；检查个位/十位写法；合并或变化量未知的应用题。生成时检查个位和小于10，不能在后续步骤悄悄引入进位。
- **cnm_p047 · 用乘法验算除法**：计算“写出的商×除数”并判断能否验算通过；求商后填写验算乘积；从被除数和商恢复除数；平均分情境；检查真假商并说明乘法依据。基础核验可自动检查，推理理由须人工核阅。起步保留已知数量点阵，较高级撤去数点支架。不会画出未知商的点阵后直接让学生照抄。
- **cnm_p060 · 简单变化规律**：固定差、交替固定步长、递增差三类序列；末项或内部缺项；判断候选填数并解释。题面明确限制规则类别，避免把有限数列当成无条件唯一规律。各家族的规则提示不同，不声称每一道都要求完全自主发现规则。
- **cnm_p224 · 等量代换**：直接代换；红→蓝→绿的两层代换；红蓝总重已知时先换成同类袋数；候选重量真假判断。链式答案必须乘上两层比例。图只画给定的等重关系，不显示未求出的单袋重量。
- **cnm_p089 · 长方形面积**：给定尺寸的单位方格；行列乘积；切去一条后的剩余面积；面积反求边长；周长反求面积；剩余面积恢复原长；同周长图形的面积比较。涉及周长的任务声明其前置点 `cnm_p078`。单位方格行列与给定尺寸一致；未知边示意图不按解出的边长画格。

每个点跨支持维度/等级提供至少三类任务结构；这不是说每一个维度、每一个等级都有三类独立任务，也不把换数字当作新增家族。

## 作答与难度

`QuestionV2.student.blocks` 必须包含完整实际题干，不能只放“观察图示”之类通用说明。`student.tasks` 与 `answerSpec.parts` 一一对应；教师页列出所有小问、单位、中文判断和解答，而不只列一个主数字。

推理题同时收集判断、实际数值和理由。真假在候选池内均有，题干不预告“他说错了”。数值正确但理由未核阅时，整题不得自动计为全对。基础验算不强迫写一篇解释，也不将所有普通核算变成人工评分题。

三级为设计分级，依据支架、未知位置、关系链和任务负担，而非实测学生能力量尺。部分家族仍是同结构的参数变化。所有样板及来源仍需一线教师审核，尤其是教材版本和实际授课进度。

## 回归证据

- `tests/pilots.test.js`：支持范围、确定性、家族、图示与主答案接口。
- `tests/pilot-math-v2.test.js`：实际题干进入学生投影；独立复算两层重量比例；主答案与类型化判题一致；六点判断池均有真假；基础验算可自动检查。
- `tests/engine.test.js`：从题干独立复算算式、规律、面积/周长，验证唯一解、数域、整十与不进位等约束。
- `tests/integration-v2.test.js`：源题纠正、全链数域、样板家族与人工评分状态。
- `tests/print-edge.browser.mjs`、生产45组PDF：真实字号、空间和分页另行验收，不以单元测试代替成品检查。
