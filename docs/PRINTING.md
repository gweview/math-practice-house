# 打印与分页约定

## 学生卷

- A4（210×297 mm），左右14 mm；当前题目内容区从40 mm到270 mm，页眉和页脚单独预留。
- 支持单/双栏。短题可配成一行两题；推理、绘图、应用或明确声明跨栏的题独占一行。没有相邻配对的题按实际整栏宽度测量，不能先量半栏、再显示整栏。
- 字体加载完成后测量实际DOM，按行的最大高度装箱；分区标题一起计入。题卡不跨页。超过单页容量时明确报错，不自动缩字或裁切。
- 一年级题干14 pt，其余题干12 pt。题号/来源说明较小；一年级小问10 pt。不是靠缩小数字换取页数。
- 紧凑口算仅简化“单个数字回答、纯文字算式”的排版：保留式中空格，省去重复“我的答案”和泛用草稿线。图示、多问、选择与应用题不会被强制套进口算格式。
- 多小问各有作答线；理由/绘图使用独立人工作答区，不再重复增加一块相同的泛用空白。紧凑预设不能压缩题目声明的必要书写区。思维预设的人工区至少35 mm，测量树与成品必须使用同一规则。
- 单位方格按给定行列生成SVG。未知边仅画非比例示意，不能把解出的边长变成可数的方格。

## 教师答案与预览

教师答案独立分页，列出全部小问、中文选择结果、单位和讲解；理由/绘图明确标为人工核阅。当前答案页默认带讲解，未提供另一套独立的“只列紧凑答案”切换。

预览与浏览器打印复用同一页模型。`显示参考答案（教师）` 控制在线卡片，`打印独立答案页` 单独控制打印；预览对象只筛选屏幕预览，不改变答案复选框的打印选择。JSON导出包含教师数据，不是学生无答案卷。

异步分页使用离线staging和递增epoch，只有最新请求可以写入当前打印根节点。过时的分页返回值也不能触发打印，避免快速切换答案选项或等待字体期间恢复已关闭的答案页。

## 可执行验收

```bash
npm run test:print-edges
node tests/review-ui-regressions.mjs
node tests/preview-smoke.mjs
npm run build
npm run test:production
npm run test:pdf
```

- `print-edge` 检查长种子元数据、必要书写区、教师内容预算，并固定验证18道短算式单页和6道混合题两页的回归样张；不是对任意6题都承诺两页。
- `review-ui-regressions` 暂停字体ready，复现答案开关竞态；核对思维题测量/成品的35 mm人工区，以及两种栏数的内容/页脚边界；同时验证知识地图切换后的容量不沿用旧配置。
- `production-v2` 在实际dist上操作控件。45组覆盖三年级段、6/12/18题、单/双栏、答案开/关、六样板思维组合与三个紧凑口算组合；每例落盘，整批结束后才标记 `complete: true`。
- PDF验收要求实际页数等于显式DOM页数；每页至少有真实题号；所有题号恰好出现一次；完整实际题干存在；教师讲解完整；无学生/教师标题串页。只检查文本长度无法排除来源说明孤页。

还需人工检查代表页的可读性、纸张利用率、图文关系与书写便利。长图示/推理题和短口算的合理页数不同；不存在对任意主题都通用的最小页数保证。Chromium通过也不代表所有浏览器、打印机与用户缩放设置已经验证。
