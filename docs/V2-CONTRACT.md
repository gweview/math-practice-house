## QuestionV2 is additive to legacy question
Retain id,topicId,topicName,grade,dimension,level,prompt,answer:string,explanation,hint,choices?,source,fingerprint.
Add schemaVersion:2, templateId, familyId, representation, skills:string[], prerequisites:string[], difficultyDescriptor:{steps:number,reasoningMoves:string[],numberRange?:number,carry?:string,languageLoad?:string,support?:string}, student:{blocks:StudentBlock[],tasks:StudentTask[]}, answerSpec:AnswerSpec, solution:{steps:string[]}, layout:{workspaceKind:'inline'|'short'|'vertical'|'application'|'reasoning'|'drawing',minWritingMm:number,preferredSpan:1|2,keepTogether:true}.
Legacy records in localStorage may lack all new fields: render through a safe adapter/fallback without regenerating/rewriting old questions.
StudentBlock:
- {type:'text'|'equation',text:string}
- {type:'diagram',kind:'tenframe'|'array'|'numberline'|'balance'|'rectangle'|'sequence'|'table'|'clock'|'fraction',data:object}
Data conventions: tenframe {filled:number,added?:number,totalSlots?:number}; array {rows:number,columns:number}; numberline {min,max,start?,jumps?:[{by:number,label?:string}]}; balance {left:[{symbol:string,label?:string,count:number}],right:[same]}; rectangle {widthUnits:number|null,heightUnits:number|null,widthLabel:string,heightLabel:string,showGrid:boolean}; sequence {items:string[],ruleHint?:string}; table {headers:string[],rows:string[][]}; clock {hour,minute}; fraction {parts,shaded}. Diagram data only carries GIVEN student-visible facts, not secret solved quantities. Renderer whitelists every kind and escapes text; no arbitrary HTML.
StudentTask: {id:string,label:string,kind:'number'|'choice'|'text'|'manual',options?:[{key,text}]}.
AnswerSpec: {kind:'scalar'|'quantity'|'choice'|'tuple'|'multipart'|'rubric',value?:string,unit?:string,aliases?:string[],parts?:[{id:string,spec:AnswerSpec}],manual?:boolean}. For choice use value=correct key. Tuple value comma-separated quotient/remainder or parts. Legacy answer remains canonical primary value for compatibility; multipart UI uses assessAnswer, not checkAnswer for full completion.
